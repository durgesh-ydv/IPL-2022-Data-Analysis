# 🏏 IPL 2022 Data Analysis

## 📌 Introduction

The **Indian Premier League (IPL)** is one of the most popular T20 cricket leagues in India. This project analyzes **IPL 2022 match data** using Python to explore team performance, toss decisions, match results, player performances, scoring patterns, and other match-level insights.

The project focuses on **Exploratory Data Analysis (EDA)** and presents the findings through data-driven visualizations.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze IPL 2022 match results
* Identify team performance patterns
* Analyze toss decisions and their outcomes
* Explore batting and bowling performances
* Analyze scoring patterns across matches
* Compare match outcomes and winning margins
* Analyze venue-level match information
* Generate meaningful insights using data visualization

---

## 🛠️ Technologies & Libraries

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical data visualization
* **Jupyter Notebook** – Data analysis environment

## 📂 Dataset

The dataset contains match-level information from **IPL 2022**.

### Dataset Features

| Column                | Description                    |
| --------------------- | ------------------------------ |
| `match_id`            | Unique match identifier        |
| `date`                | Match date                     |
| `venue`               | Match venue                    |
| `team1`               | First team                     |
| `team2`               | Second team                    |
| `stage`               | Tournament stage               |
| `toss_winner`         | Team that won the toss         |
| `toss_decision`       | Toss decision                  |
| `first_ings_score`    | First innings score            |
| `first_ings_wkts`     | Wickets lost in first innings  |
| `second_ings_score`   | Second innings score           |
| `second_ings_wkts`    | Wickets lost in second innings |
| `match_winner`        | Match-winning team             |
| `won_by`              | Winning method                 |
| `margin`              | Winning margin                 |
| `player_of_the_match` | Player of the Match            |
| `top_scorer`          | Top scorer of the match        |
| `highscore`           | Highest individual score       |
| `best_bowling`        | Best bowling performer         |
| `best_bowling_figure` | Best bowling figure            |

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/IPL-2022-Data-Analysis.git
```

### 2. Navigate to the project directory

```bash
cd IPL-2022-Data-Analysis
```

### 3. Install the required libraries

```bash
pip install pandas NumPy matplotlib seaborn jupyter
```

### 4. Open the notebook

```bash
jupyter notebook
```

Then open:

```text
IPL_2022_Data_Analysis.ipynb
```

Run the cells sequentially to reproduce the analysis.
